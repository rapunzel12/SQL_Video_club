# 💡 Lessons Learned

## 🏗️ Key Adjustments Between MySQL & PostgreSQL
- **AUTO_INCREMENT** → Replaced with `SERIAL`.
- **String Formatting** → Only **single quotes ('')** are used in PostgreSQL.
- **JOIN Differences** → **Explicit JOINs** are preferable in PostgreSQL.
